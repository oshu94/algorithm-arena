# Algorithm Arena: Think. Predict. Discover.

Algorithm Arena is an interactive sorting game that helps users learn sorting algorithms by making decisions during the sorting process.

Instead of only reading about algorithms, players compare numbers, predict what should happen next, and see how the array changes. The game also gives feedback, awards points, and tracks streaks to make learning more engaging.

## Features

- **Three sorting algorithms:** Bubble Sort, Selection Sort, and Insertion Sort.
- **Interactive gameplay:** Make decisions as you work through the sorting process.
- **Instant feedback:** See whether your choice was correct, with explanations for each step.
- **Scoring system:** Earn points as you play.
- **Streak tracking:** Keep track of consecutive correct answers.
- **Replay:** Play again to practise and improve your understanding.
- **Keyboard and mouse controls:** Navigate and play using arrow keys, Enter, or mouse clicks.
- **TV-screen testing:** Tested the website in an Android TV 1080p emulator using a TV browser.

## How to Play

1. Choose a sorting algorithm.
2. Look at the numbers presented in the current step.
3. Predict the correct action.
4. Confirm your choice and read the feedback.
5. Continue until the sorting round is complete.
6. Check your score and streak, then replay if you want to practise again.

## Controls

- **Left / Right Arrow:** Move between the available choices.
- **Enter:** Confirm your choice.
- **Mouse:** Click the on-screen controls.

## Run the Project

You can run Algorithm Arena directly in a modern web browser.

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start playing. No installation or additional dependencies are required.
