# Algorithm Arena: Think. Predict. Discover.

A TV-style game that teaches Bubble Sort. You see two neighbouring numbers and
predict: swap or keep? The array updates, you get an explanation (with a little
sarcasm), points, and a streak. Sort all 15 steps to finish.

## Run it
Open `index.html` in any modern browser. No install, no dependencies.

## Controls
- Left / Right arrow: move between Swap and Keep
- Enter: confirm
- Mouse click also works

## Built with
Plain HTML, CSS and vanilla JavaScript.

## Status (honest version)
- Works: full Bubble Sort game, scoring, streaks, replay, keyboard and mouse input.
- Tested: desktop browser on Windows, keyboard and mouse.
- NOT tested: Fire TV, Fire OS, or any emulator. This is not a packaged Fire TV app.
